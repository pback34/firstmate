# Spec Gate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the captain approve executable Gherkin scenarios before implementation, and make a promoted ship task's gated `done:` refuse until the locked scenarios are unchanged and all pass at the named head.

**Architecture:** One new side-effect-free library (`bin/fm-spec-lib.sh`) owns the lock and record formats, the Gherkin keyword parser, the Cucumber JSON reader, and the gate checks.
Two thin CLIs use it: `bin/fm-spec.sh` (firstmate side: show, approve) and `bin/fm-acceptance.sh` (worker side: run).
Existing scripts gain small opt-in hooks: `fm-project-mode.sh --acceptance`, `fm-brief.sh --spec --acceptance`, an `fm-spawn.sh` agreement check, `fm-promote.sh` contract and preflight, and one call at the top of `fm_dod_accept_ship_done` plus an `fm-pr-check.sh` shortcut exemption.

**Tech Stack:** Bash (stock macOS Bash 3.2 compatible: no `mapfile`, associative arrays, or `${var,,}`), POSIX awk, jq, git.

**Spec:** `docs/superpowers/specs/2026-10-12-spec-gate-design.md`

## Global Constraints

- Opt-in only: a task without `spec_lock=` in its meta must behave byte-for-byte as before on every path.
- The no-mistakes pre-validation `done:` stays ungated (`fm_dod_should_gate_ship_done` is unchanged).
- Firstmate supervision never executes project code; only the worker-invoked `fm-acceptance.sh` runs the entrypoint.
- Spec directory is fixed at `features/`; Gherkin keywords are English only.
- Status map is closed: `passed failed undefined pending skipped ambiguous unknown`; worst-first order `failed ambiguous unknown undefined pending skipped passed`; only `passed` passes; a zero entrypoint exit is required.
- pytest-bdd is unsupported (its Cucumber JSON omits undefined steps and reports skips as `passed`).
- Repo style (`.agents/skills/firstmate-coding-guidelines/SKILL.md`): one sentence per line in Markdown, plain `-` dashes, no agent co-author trailers in commits, shellcheck-clean `bin/` scripts, colocated `tests/<subject>.test.sh` through public interfaces only, never asserting source bytes.
- Every new tracked Markdown file gets an entry in `docs/documentation-audiences.json`; `bin/fm-doc-audience-check.sh` must pass.
- Every new test file is added to `family_for_basename()` and `portable_serial_weight_hints()` in `bin/fm-test-run.sh`.
- Refusals in bin scripts print `error: ...` to stderr; follow each touched script's existing exit codes.

## Review Focus

- A feature file saved with CRLF line endings must parse to the same scenarios as its LF twin (test in Task 1).
- A feature path containing spaces must lock, archive, restore, and pass the gate (test in Task 3).
- An entrypoint that commits or checks out during the run must not produce a record bound to the wrong head (test in Task 6).
- A re-approval must never let the previous spec's `acceptance.json` satisfy the new lock (test in Task 5).
- A runner reporting `uri` as the physical absolute path while the worktree is passed through a symlink must still normalize (test in Task 2).

```bash
#!/usr/bin/env bash
# fm-spec-lib.sh - the spec gate's single contract owner (sourced, side-effect free).
#
# A spec scout's captain-approved Gherkin scenarios are archived under
# data/<id>/spec/ and locked in data/<id>/spec-lock.json; the task record
# carries spec_lock=<absolute lock path>. The worker records its acceptance run
# in the lock's sibling acceptance.json. docs/superpowers/specs/2026-10-12-spec-gate-design.md
# is the design; this header owns the formats.
#
# Lock (version 1):
#   {version, task, commit, approved_at, approval,
#    files: [{path, sha256}],
#    scenarios: [{uri, line, name, steps[, outline_line, ordinal]}]}
# Record (version 1):
#   {version, head, ran_at, entrypoint, exit,
#    scenarios: [{uri, line, name, steps, status}],
#    counts: {passed, failed, undefined, pending, skipped, ambiguous, unknown}}
#
# Scenario identity is (uri, line). Outline rows also carry outline_line and a
# 1-based ordinal because some runners report every row at the outline's line.
# steps counts a scenario's own steps plus the Background steps that apply to
# it. The parser understands English keywords only.

[ -z "${FM_SPEC_LIB_SOURCED:-}" ] || return 0
FM_SPEC_LIB_SOURCED=1

fm_spec_sha256() {  # reads stdin, prints the hex digest
  if command -v sha256sum >/dev/null 2>&1; then
    sha256sum | cut -d' ' -f1
  else
    shasum -a 256 | cut -d' ' -f1
  fi
}

fm_spec_parse_feature() {  # <file> <uri>
  awk -v uri="$2" '
    function bg() { return fbg + (in_rule ? rbg : 0) }
    function title(s) { sub(/^[^:]*:[ \t]*/, "", s); sub(/[ \t]+$/, "", s); return s }
    function flush() {
      if (kind == "scenario") printf "%s\t%d\t%d\t\t\t%s\n", uri, sline, bg() + own, sname
      kind = ""
    }
    {
      t = $0
      sub(/\r$/, "", t)
      sub(/^[ \t]+/, "", t)
      if (t ~ /^("""|```)/) { doc = !doc; next }
      if (doc || t == "" || t ~ /^#/ || t ~ /^@/) next
      if (t ~ /^Rule:/) { flush(); in_rule = 1; rbg = 0; mode = ""; next }
      if (t ~ /^Background:/) { flush(); mode = in_rule ? "rbg" : "fbg"; next }
      if (t ~ /^Scenario (Outline|Template):/) { flush(); mode = "outline"; oline = NR; oname = title(t); own = 0; ord = 0; next }
      if (t ~ /^(Scenario|Example):/) { flush(); mode = "scenario"; kind = "scenario"; sline = NR; sname = title(t); own = 0; next }
      if (t ~ /^(Examples|Scenarios):/) { if (mode == "outline" || mode == "examples") { mode = "examples"; header = 0 }; next }
      if (t ~ /^(Given|When|Then|And|But)[ \t]/ || t ~ /^\*[ \t]/) {
        if (mode == "fbg") fbg++
        else if (mode == "rbg") rbg++
        else if (mode == "scenario" || mode == "outline") own++
        next
      }
      if (t ~ /^\|/ && mode == "examples") {
        if (!header) { header = 1; next }
        ord++
        printf "%s\t%d\t%d\t%d\t%d\t%s\n", uri, NR, bg() + own, oline, ord, oname
      }
    }
    END { flush() }
  ' "$1"
}

fm_spec_inventory() {  # <root>
  local root=$1
  (cd "$root" && find features -type f -name '*.feature' 2>/dev/null | LC_ALL=C sort) \
    | while IFS= read -r rel; do fm_spec_parse_feature "$root/$rel" "$rel"; done \
    | jq -R -s -c '[split("\n")[] | select(length > 0) | split("\t")
        | {uri: .[0], line: (.[1] | tonumber), name: (.[5:] | join("\t")), steps: (.[2] | tonumber)}
          + (if .[3] != "" then {outline_line: (.[3] | tonumber), ordinal: (.[4] | tonumber)} else {} end)]'
}

fm_spec_build_lock() {  # <root> <task> <commit> <approval> <approved-at>
  local root=$1 files scen
  scen=$(fm_spec_inventory "$root") || return 1
  files=$( (cd "$root" && find features -type f -name '*.feature' | LC_ALL=C sort) \
    | while IFS= read -r p; do printf '%s\t%s\n' "$p" "$(fm_spec_sha256 < "$root/$p")"; done \
    | jq -R -s -c '[split("\n")[] | select(length > 0) | split("\t") | {path: .[0], sha256: .[1]}]') || return 1
  jq -n -c --arg task "$2" --arg commit "$3" --arg approval "$4" --argjson at "$5" \
    --argjson files "$files" --argjson sc "$scen" \
    '{version: 1, task: $task, commit: $commit, approved_at: $at, approval: $approval, files: $files, scenarios: $sc}'
}
```

fm_spec_record_from_cucumber() {  # <cucumber-json> <worktree> <head> <entrypoint> <exit> <ran-at>
  local real
  real=$(cd "$2" 2>/dev/null && pwd -P) || real=$2
  jq -c --arg wt "$2" --arg real "$real" --arg head "$3" --arg ep "$4" --argjson exit "$5" --argjson ran "$6" '
    def strip($p): if startswith($p + "/") then .[($p | length) + 1:] else . end;
    def norm: sub("^classpath:"; "") | sub("^file:(//)?"; "") | gsub("\\\\"; "/")
      | strip($wt) | strip($real) | sub("^\\./"; "");
    def canon: . as $s | if (["passed","failed","undefined","pending","skipped","ambiguous"] | any(. == $s)) then $s else "unknown" end;
    def rank: {"passed":0,"skipped":1,"pending":2,"undefined":3,"unknown":4,"ambiguous":5,"failed":6}[.];
    def worst: if length == 0 then "unknown" else max_by(rank) end;
    def hook: (.hidden == true) or (((.keyword // "") | gsub("^\\s+|\\s+$"; "")) as $k | $k == "Before" or $k == "After");
    def results: [(.before[]?, .steps[]?, .after[]?) | (.result.status // "unknown") | ascii_downcase | canon];
    [ .[] | (.uri | norm) as $u
      | (.elements // []) | reduce .[] as $e ({bg: null, out: []};
          if ($e.type // "scenario") == "background" then .bg = $e
          else .out += [{e: $e, bg: .bg}] | .bg = null end)
      | .out[]
      | { uri: $u, line: .e.line, name: (.e.name // ""),
          steps: ([(.bg // {}).steps[]?, .e.steps[]? | select(hook | not)] | length),
          status: (((.bg // {}) | results) + (.e | results) | worst) } ] as $sc
    | { version: 1, head: $head, ran_at: $ran, entrypoint: $ep, exit: $exit, scenarios: $sc,

fm_spec_gate_scenarios() {  # <lock> <record>
  jq -r -n --slurpfile L "$1" --slurpfile R "$2" '
    def at($rs; $u; $l): [$rs[] | select(.uri == $u and .line == $l)];
    def find($rs; $s): (at($rs; $s.uri; $s.line)[0])
      // (if $s.outline_line then at($rs; $s.uri; $s.outline_line)[$s.ordinal - 1] else null end);
    ($L[0].scenarios) as $ls | ($R[0].scenarios) as $rs
    | [$ls[] | select(find($rs; .) == null) | "\(.uri):\(.line)"] as $notrun
    | [$ls[] | . as $s | find($rs; $s) | select(. != null and .steps < $s.steps)
        | "\($s.uri):\($s.line) unknown(steps \(.steps)/\($s.steps))"] as $short
    | [$rs[] | select(.status != "passed") | "\(.uri):\(.line) \(.status)"] as $bad
    | (if ($notrun | length) > 0 then "notrun " + ($notrun | join(" ")) else empty end),
      (if (($short + $bad) | length) > 0 then "notpassing " + (($short + $bad) | unique | join(" ")) else empty end)
  '
}

# 0 when the locked spec passes at <worktree>'s HEAD; otherwise one reason line
# on stdout and 1. The checks run in the order the design's gate table lists.
fm_spec_gate() {  # <lock> <worktree>
  local lock=$1 wt=$2 head rec rhead ex out notrun bad changed
  if [ ! -r "$lock" ] || ! jq -e '.version == 1 and (.files | type == "array") and (.scenarios | type == "array")' "$lock" >/dev/null 2>&1; then
    printf '%s\n' "spec lock unreadable"
    return 1
  fi
  if [ -z "$wt" ] || [ ! -d "$wt" ] || ! head=$(git -C "$wt" rev-parse --verify HEAD 2>/dev/null); then
    printf '%s\n' "named head cannot be verified for a locked spec"
    return 1
  fi
  changed=$(jq -r '.files[] | "\(.sha256) \(.path)"' "$lock" | while IFS=' ' read -r want path; do
    if ! git -C "$wt" cat-file -e "HEAD:$path" 2>/dev/null \
      || [ "$(git -C "$wt" show "HEAD:$path" | fm_spec_sha256)" != "$want" ]; then
      printf '%s\n' "$path"
    fi
  done | paste -sd' ' -)
  if [ -n "$changed" ]; then
    printf 'locked spec changed: %s; needs captain re-approval\n' "$changed"
    return 1
  fi
  rec="${lock%/*}/acceptance.json"
  if [ ! -r "$rec" ] || ! rhead=$(jq -er '.head' "$rec" 2>/dev/null); then
    printf '%s\n' "acceptance run missing"
    return 1
  fi
  if [ "$rhead" != "$head" ]; then
    printf 'acceptance run is for %s, not head %s; rerun fm-acceptance.sh as the last step\n' "$rhead" "$head"
    return 1
  fi
  ex=$(jq -r '.exit' "$rec")
  if [ "$ex" != 0 ]; then
    printf 'acceptance entrypoint exited %s\n' "$ex"
    return 1
  fi
  out=$(fm_spec_gate_scenarios "$lock" "$rec") || { printf '%s\n' "acceptance run unreadable"; return 1; }
  notrun=$(printf '%s\n' "$out" | sed -n 's/^notrun //p')
  bad=$(printf '%s\n' "$out" | sed -n 's/^notpassing //p')
  if [ -n "$notrun" ]; then
    printf 'scenarios not run: %s\n' "$notrun"
    return 1
  fi
  if [ -n "$bad" ]; then
    printf 'scenarios not passing: %s\n' "$bad"
    return 1
  fi
  return 0
}

fm_spec_archive_matches_lock() {  # <lock>
  local lock=$1 bad
  [ -r "$lock" ] && jq -e '.version == 1' "$lock" >/dev/null 2>&1 || { printf '%s\n' "spec lock unreadable"; return 1; }
  bad=$(jq -r '.files[] | "\(.sha256) \(.path)"' "$lock" | while IFS=' ' read -r want path; do
    f="${lock%/*}/spec/$path"
    if [ ! -f "$f" ] || [ "$(fm_spec_sha256 < "$f")" != "$want" ]; then printf '%s\n' "$path"; fi
  done | paste -sd' ' -)
  [ -z "$bad" ] || { printf 'archived spec does not match the lock: %s\n' "$bad"; return 1; }
}

fm_spec_ship_contract() {  # <task-id> <lock> <entrypoint> <fm-root> <fm-home>
  local id=$1 lock=$2 ep=$3 root=$4 home=$5 dir=${2%/*}
  cat <<EOF
# Locked acceptance spec
Spec lock: $lock
The captain approved the scenarios archived in \`$dir/spec/features/\`; they are locked by content hash.
1. Before implementing, restore them into this branch unchanged with \`mkdir -p features && cp -R "$dir/spec/features/." features/\`, and commit them as your branch's first commit.
2. Never edit, rename, delete, tag-filter, or skip a locked feature file or scenario. If a scenario looks wrong or impossible, stop and escalate to firstmate; only the captain can change the spec.
3. Implement test-first and make every locked scenario executable through \`$ep\`: run from the worktree root with one argument, an absolute path, it must write a Cucumber JSON report there and exit 0 only when everything passed. Create it if the project lacks it.
4. As your LAST step, run \`FM_HOME=$home $root/bin/fm-acceptance.sh run $id\`: after implementation, after any no-mistakes pipeline fixes are in this copy (and after Gerrit custody recovery where it applies), on the exact head your ready report names, with no commits afterwards.
5. Your ready \`done:\` is refused until the locked files are unchanged at that head and the recorded run shows exit 0 with every scenario passed. If it is refused, rerun step 4; re-implement only when the refusal names failing scenarios.
EOF
}
```

# fm-spec.sh - firstmate's spec-gate CLI (supervision side; never runs project code).
#
# Usage:
#   fm-spec.sh show <task-id>
#   fm-spec.sh approve <task-id> --decision-file <path> [--hold <backlog-id>]

# show prints the task's locked scenarios, or, before approval, the candidate
# scenarios committed under features/ in the task worktree.

# (default <task-id>) through fm-captain-hold.sh answer --release, then archives
# features/**/*.feature exactly as committed at the worktree HEAD into
# data/<id>/spec/, writes data/<id>/spec-lock.json, and records

approve() {  # <id> <args...>
  local id=$1 hold words='' meta dir kind wt commit files lock_json n tmp
  shift
  hold=$id
  while [ $# -gt 0 ]; do
    case "$1" in
      --decision-file) words=${2:-}; shift 2 || usage ;;
      --hold) hold=${2:-}; shift 2 || usage ;;
      *) usage ;;
    esac
  done
  [ -n "$words" ] && [ -s "$words" ] || die "approve needs --decision-file <path> holding the captain's exact approval words"
  meta="$STATE/$id.meta"
  dir="$DATA/$id"
  [ -r "$meta" ] || die "no task record for $id"
  kind=$(meta_value "$meta" kind)
  case "$kind" in
    scout) ;;
    ship) [ -n "$(meta_value "$meta" spec_lock)" ] || die "$id is a ship task without a spec lock; only a spec scout or a locked ship can be approved" ;;
    *) die "$id is kind=${kind:-unknown}; only a spec scout or a locked ship can be approved" ;;
  esac
  wt=$(meta_value "$meta" worktree)
  [ -n "$wt" ] && [ -d "$wt" ] && git -C "$wt" rev-parse --git-dir >/dev/null 2>&1 \
    || die "worktree for $id is missing or not a git copy (${wt:-none}); nothing was written"
  commit=$(git -C "$wt" rev-parse --verify HEAD 2>/dev/null) || die "cannot resolve HEAD in $wt"
  [ -z "$(git -C "$wt" status --porcelain -- features)" ] || die "uncommitted changes under features/ in $wt; the spec must be committed first"
  files=$(git -C "$wt" ls-tree -r --name-only HEAD -- features | grep '\.feature$' || true)
  [ -n "$files" ] || die "no committed features/**/*.feature files at $commit in $wt"
  mkdir -p "$dir"
  STAGE="$dir/.spec.stage.${BASHPID:-$$}"
  rm -rf -- "$STAGE"
  printf '%s\n' "$files" | while IFS= read -r p; do
    mkdir -p "$STAGE/$(dirname "$p")" && git -C "$wt" show "HEAD:$p" > "$STAGE/$p" || exit 1
  done || die "could not archive the feature files from $commit"
  lock_json=$(fm_spec_build_lock "$STAGE" "$id" "$commit" \
    "captain-hold:$hold sha256:$(fm_spec_sha256 < "$words")" "$(date +%s)") || die "could not build the spec lock"
  [ "$(printf '%s' "$lock_json" | jq '.scenarios | length')" -gt 0 ] || die "the features at $commit define no scenarios"
  "$CAPTAIN_HOLD" answer "$hold" --decision-file "$words" --release \
    || die "the captain's approval could not be recorded as a release on $hold; resolve the captain-hold record first"

  META_LOCK=$(fm_meta_lock_path "$meta") || die "invalid task record path $meta"
  fm_lock_acquire_wait "$META_LOCK"
  META_LOCK_HELD=1
  if [ -e "$dir/spec-lock.json" ]; then
    n=1
    while [ -e "$dir/spec-lock.$n.json" ]; do n=$((n + 1)); done
    mv -- "$dir/spec-lock.json" "$dir/spec-lock.$n.json"
    [ ! -d "$dir/spec" ] || mv -- "$dir/spec" "$dir/spec.$n"
    [ ! -e "$dir/acceptance.json" ] || mv -- "$dir/acceptance.json" "$dir/acceptance.$n.json"
  fi
  mv -- "$STAGE" "$dir/spec"
  STAGE=
  printf '%s\n' "$lock_json" > "$dir/spec-lock.json.tmp" && mv -- "$dir/spec-lock.json.tmp" "$dir/spec-lock.json" \
    || die "could not write $dir/spec-lock.json"
  tmp="$STATE/.$id.meta.spec.${BASHPID:-$$}"
  { grep -v '^spec_lock=' "$meta"; echo "spec_lock=$dir/spec-lock.json"; } > "$tmp"
  if ! fm_backlog_atomic_transition publish "$tmp" "$meta" "task record" "$STATE"; then
    rm -f -- "$tmp"
    die "task record for $id could not be published ($FM_BACKLOG_TRANSITION_ERROR)"
  fi
  fm_lock_release "$META_LOCK"
  META_LOCK_HELD=0
  echo "locked $(printf '%s' "$lock_json" | jq '.scenarios | length') scenarios in $(printf '%s' "$lock_json" | jq '.files | length') files at $commit: $dir/spec-lock.json"
}

  approve) [ -n "${2:-}" ] || usage; id=$2; shift 2; approve "$id" "$@" ;;
  *) usage ;;
esac

#!/usr/bin/env bash
# fm-acceptance.sh - record a spec-locked task's acceptance run (worker-invoked).
#
# Usage:
#   fm-acceptance.sh run <task-id>
#
# Runs the entrypoint named by data/<id>/brief.md's "Acceptance entrypoint:"
# line from the physical worktree root with one argument, the absolute path
# where it must write a Cucumber JSON report, and writes data/<id>/acceptance.json
# bound to the worktree HEAD (format owned by bin/fm-spec-lib.sh).
# Refuses, writing no record, on: a dirty worktree, a missing or non-executable
# entrypoint, a HEAD that moves during the run, or no readable report.
# Exit: 0 recorded and passing; 1 recorded but not passing; 2 refused.
set -u

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
FM_ROOT="${FM_ROOT_OVERRIDE:-$(cd "$SCRIPT_DIR/.." && pwd)}"
FM_HOME="${FM_HOME:-${FM_ROOT_OVERRIDE:-$FM_ROOT}}"
STATE="${FM_STATE_OVERRIDE:-$FM_HOME/state}"
DATA="${FM_DATA_OVERRIDE:-$FM_HOME/data}"
# shellcheck source=bin/fm-spec-lib.sh
. "$SCRIPT_DIR/fm-spec-lib.sh"

refuse() { echo "error: $*" >&2; exit 2; }
[ "${1:-}" = run ] && [ -n "${2:-}" ] || { sed -n '4,5p' "$0" >&2; exit 2; }
ID=$2
META="$STATE/$ID.meta"
[ -r "$META" ] || refuse "no task record for $ID at $META"
WT=$(grep '^worktree=' "$META" | tail -1 | cut -d= -f2-)
[ -n "$WT" ] && [ -d "$WT" ] || refuse "task $ID has no worktree on record"
WT=$(cd "$WT" && pwd -P)
EP=$(sed -n 's/^Acceptance entrypoint: //p' "$DATA/$ID/brief.md" 2>/dev/null | head -n 1)
[ -n "$EP" ] || refuse "$DATA/$ID/brief.md records no Acceptance entrypoint"
[ -x "$WT/$EP" ] || refuse "acceptance entrypoint $EP is missing or not executable in $WT"
[ -z "$(git -C "$WT" status --porcelain)" ] || refuse "$WT has uncommitted changes; commit before recording acceptance"
HEAD_BEFORE=$(git -C "$WT" rev-parse --verify HEAD 2>/dev/null) || refuse "cannot resolve HEAD in $WT"

OUT="$DATA/$ID/acceptance.json"
REPORT="$DATA/$ID/.cucumber.${BASHPID:-$$}.json"
TMP="$OUT.${BASHPID:-$$}.tmp"
trap 'rm -f -- "$REPORT" "$TMP"' EXIT
rm -f -- "$REPORT"
(cd "$WT" && "./$EP" "$REPORT")
EXIT=$?
HEAD_AFTER=$(git -C "$WT" rev-parse --verify HEAD 2>/dev/null)
[ "$HEAD_AFTER" = "$HEAD_BEFORE" ] || refuse "HEAD moved during the acceptance run ($HEAD_BEFORE -> ${HEAD_AFTER:-none}); no record written"
jq -e 'type == "array"' "$REPORT" >/dev/null 2>&1 \
  || refuse "the entrypoint (exit $EXIT) wrote no readable Cucumber JSON to $REPORT; no record written"
fm_spec_record_from_cucumber "$REPORT" "$WT" "$HEAD_BEFORE" "$EP" "$EXIT" "$(date +%s)" > "$TMP" \
  || refuse "could not build the acceptance record"
mv -f -- "$TMP" "$OUT"
jq -r '"recorded \(.scenarios | length) scenarios at \(.head) exit=\(.exit): "
  + ([.counts | to_entries[] | select(.value > 0) | "\(.key)=\(.value)"] | join(" "))' "$OUT"
jq -e '.exit == 0 and (.scenarios | length) > 0 and .counts.passed == (.scenarios | length)' "$OUT" >/dev/null && exit 0
exit 1
